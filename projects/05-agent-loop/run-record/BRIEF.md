# Goal Brief — p5-run-guide-hand-check
## Problem
A stranger who clones the repo cannot reproduce the Project 3 hand-check evidence or learn how to turn it into a right / missed / wrong / unconfirmed verdict.
## Success criteria (product-level)
- A stranger on macOS follows `projects/03-tech-stack-segment/RUN.md` top to bottom with a fresh clone and gets evidence files and a markers printout for 3 domains in 5 minutes or less.
- Every prerequisite (Python, curl_cffi, dig, input CSV with `domain`, `pass`, `Tech Stack`) is named with an install command before use.
- The guide defines the four verdicts in plain words, says what is not evidence, and scores one worked example that matches a row of `hand_check_25.csv` exactly.
## Out of scope
- Changing README.md numbers, `hand_check_25.csv`, or any other project.
- Re-running the 25-row check or the full 289 list.
- Any file outside `projects/03-tech-stack-segment/`.
